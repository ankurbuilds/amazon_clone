# Amazon Homepage Clone

## About the Project

This is a simple Amazon homepage clone that I made using HTML and CSS. The main aim of this project was to practice web development and learn how to create a webpage similar to the Amazon website. It includes a navigation bar, search bar, delivery address section, product categories, a hero section, and a footer.

## Technologies Used

* HTML
* CSS

## Features

* Amazon-style navigation bar
* Search bar with a category dropdown
* Delivery location and account sections
* Product category boxes with images
* Hero section with a message about Amazon India
* Footer with useful links
* Hover effects on different elements

## Files Used

* `index.html` – Contains the structure and content of the webpage.
* `style.css` – Contains the styling, layout, colors, and hover effects.
* `amazon_logo.png` – Used for the Amazon logo.
* `hero_image.jpg` – Used as the background image for the hero section.
* `box1_image.jpg` to `box8_image.jpg` – Used for the product category sections.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure all the image files are present in the same folder as the HTML and CSS files.
4. Open `index.html` in your browser to view the webpage.

## What I Learned

While making this project, I learned how to use HTML to structure a webpage and CSS to style it. I also practiced Flexbox, background images, margins, padding, hover effects, and Font Awesome icons. This project helped me understand how different sections of a website can be arranged to create a complete homepage.

## Note

This project is made for learning and practice purposes. It is a static homepage clone and does not include actual Amazon shopping, login, or search functionality.
